# ShelfSignal

Holiday toy stock and price radar. Know before the shelf goes dark.

A full-featured prototype for the Christmas 2026 sell-out list: buy/wait scores, family lists, local stock, deal calendar, alternatives, claims, and an owner dashboard.

## Run

Open `index.html` in a browser, or enable GitHub Pages on this repo (Settings → Pages → main / root).

Prices, stock, and affiliate numbers are illustrative estimates based on October 2026 holiday guides, not a live feed.

## Features

- Radar with buy-now / wait scores and restock velocity
- Family lists with secrecy mode
- Sold-out alternatives
- Local stock by ZIP
- Budget envelope
- Black Friday deal calendar
- Barcode / photo check
- Claim links so relatives don’t double-buy
- Year-round mode
- Owner dashboard (estimated affiliate revenue)
